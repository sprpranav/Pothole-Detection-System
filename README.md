# Smart Pothole Detection System

This project focuses on comparing multiple machine learning models for detecting potholes from road images. Models evaluated include ANN, KNN, SVM, deep learning with VGG16, and PCA for dimensionality reduction.

---

## Project Highlights

- Implemented and compared several models for pothole classification:
  - Artificial Neural Networks (ANN)
  - K-Nearest Neighbors (KNN)
  - Support Vector Machine (SVM)
  - Deep feature extraction with VGG16
  - Principal Component Analysis (PCA) for feature reduction

- Analyzed and compared accuracy and performance metrics to identify the best approach.

---

- Road surface images categorized as pothole or normal.
